# Daydream

Daydream is a lightweight Minecraft shader focused on making the vanilla world feel more atmospheric without completely changing its look.

## ✦ Features
- simple shadows
- warmer sunlight and block lighting
- Simple water movement that gives water waves
- Lightweight shader 

I use many vibrancy increases and exposure increases that make the World look way better with barley extra performance loss!

## ✦ Why Daydream
If you want Minecraft to look a little more alive without losing the vanilla feeling, Daydream is made for that.
Daydream is made for players who want a small visual upgrade while keeping the original Minecraft style.

## ✦ Requirements
- Requires the [Iris](https://modrinth.com/mod/iris/versions) Mod to be installed! Optifine should work aswell, though I recommend Iris! Guide on how to install further down.

## Installation Guide for Fabric not OptiFine
**Step 1: Install the Mod Loader (Fabric)**

**Note: If you already have Fabric installed (also the right verison), then you can skip to step 2**

1. Go to the official Fabric website: https://fabricmc.net
2. Press the big Download Button and download the installer for your operating system like windows or linux
3. Run the downloaded installer
4. Select the Minecraft Version and Loader Version you want to use, then click Install

**Step 2: Download the Mods**

1. Find the Mods you need to use. For this Mod you need the support mods [Iris](https://modrinth.com/mod/iris), [Sodium](https://modrinth.com/mod/sodium), [FabricAPI](https://modrinth.com/mod/fabric-api) . Find this mod under [Versions](https://github.com/Facticee/CrystalCaves/releases/)
2. Make sure the versions match.
3. Go to [My Modrinth Shader Page](https://modrinth.com/shader/daydream-shader) to download the Shader.

**Step 3: Move Mods to the Folder**

1. Press win + r and type %appdata%
2. Open the .minecraft folder. Once in the .minecraft folder, open the folder called "mods" (Note: If you dont see the mods folder, just create it)
3. Once in the mod folder, copy the mod .jar files you just downloaded, and paste them into there (the mods folder)
4. Go back into the .minecraft folder and open the folder called "shaderpacks" (Note: If you dont see the mods folder, just create it). Paste the Shader Zip in there.

**Step 4: Launch the Game like you are used to**
